Technical Support

When reporting a technical issue, please provide the following information where applicable:

  • VxLang version
  • Operating system and target architecture
  • Compiler and compiler version
  • Protection settings
  • Error messages and steps to reproduce the issue
  • Sample code that reproduces the issue (required for crashes or unexpected behavior)

When reporting a crash or unexpected behavior, you must attach a minimal sample code that reproduces the same issue to facilitate reproduction and root cause analysis.

Where possible, isolate the sample code from your actual project and ensure that the issue can be reproduced using the same protection settings.

Please do not include your license file, confidential source code, or other sensitive information in your initial inquiry.

VxLang is developed and maintained by an independent developer. Response times may vary depending on the nature of the inquiry and the development schedule.

Thank you for your interest in and support of VxLang.
